# 📚 Book Tracker

A simple and responsive web application to manage and track your reading journey.

## Features

- Add books with title, author, and reading status.
- Search books by title or author.
- Update reading status (To Read, Reading, Finished).
- Delete books from the list.
- View reading statistics.
- Save books using localStorage, even after refreshing the page.
- Responsive design for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start adding and managing your books.
